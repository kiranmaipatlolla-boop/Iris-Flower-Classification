🌷 Iris Flower Classifier

📌 About
A Machine Learning project that predicts the species of an Iris flower using its sepal and petal measurements.

🎯 Objective
To build and compare classification models for predicting:
- Iris-setosa
- Iris-versicolor
- Iris-virginica

📊 Dataset
The Iris dataset contains 150 records and 4 features:
- Sepal Length
- Sepal Width
- Petal Length
- Petal Width

🤖 Algorithms Used
- Logistic Regression
- K-Nearest Neighbors (KNN)
- Decision Tree

🛠️ Technologies
Python, Pandas, NumPy, Matplotlib, Seaborn, Scikit-learn, Jupyter Notebook

🔄 Workflow
Data Collection → Data Cleaning → EDA → Data Visualization → Model Training → Model Evaluation → Prediction

📈 Result
The baseline models achieved **93.33% test accuracy** on the selected test dataset.
